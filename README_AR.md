# 🌾 جنة خالية من القمح - تطبيق التجارة الإلكترونية

تطبيق تجارة إلكترونية احترافي مخصص لتوفير منتجات عالية الجودة ومعتمدة خالية من الجلوتين وحساسية القمح، بما في ذلك الخبز والحلويات والوجبات الخفيفة وخلطات الخبز.

## 🎯 المميزات

### للعملاء
- **كتالوج المنتجات**: تصفح المنتجات المصنفة حسب الفئة (خبز، حلويات، وجبات خفيفة، خلطات خبز)
- **معلومات الحساسية**: وسم مفصل للحساسية والشهادات
- **المصادقة الآمنة**: تسجيل وتسجيل دخول آمن
- **سلة التسوق**: إضافة وإزالة العناصر مع التحديثات في الوقت الفعلي
- **البحث والترتيب**: ابحث وصنف حسب السعر والتقييم والصلة
- **مراجعات المستخدمين**: اقرأ واترك تقييمات المنتجات
- **إدارة الطلبات**: تتبع طلباتك وسجل الطلبات

### للمسؤولين
- **إدارة المنتجات**: إضافة وتحديث وإدارة المنتجات
- **التحكم في المخزون**: إدارة المخزون في الوقت الفعلي
- **تتبع الطلبات**: مراقبة وتحديث حالات الطلبات
- **إدارة المستخدمين**: إدارة حسابات العملاء والبيانات

## 🛠️ مكدس التكنولوجيا

### الواجهة الخلفية
- **Node.js** مع Express.js
- **MongoDB** لقاعدة البيانات
- **JWT** للمصادقة
- **Bcrypt** لتجزئة كلمات المرور
- **Stripe** لمعالجة الدفع

### الواجهة الأمامية
- **React 18** مع React Router
- **Zustand** لإدارة الحالة
- **CSS3** للتصميم سريع الاستجابة
- **Axios** لاستدعاءات API
- **دعم اللغات المتعددة** - العربية والإنجليزية

## 🌍 دعم اللغات المتعددة

التطبيق يدعم:
- **الإنجليزية** (EN)
- **العربية** (AR) - مع الدعم الكامل للكتابة من اليمين إلى اليسار (RTL)

### المميزات المتعلقة باللغات
- تبديل سريع بين اللغات من الرأس
- الحفظ التلقائي لتفضيلات اللغة
- دعم كامل لـ RTL
- ترجمة شاملة لجميع نصوص الواجهة

## 🚀 البدء السريع

### المتطلبات
- Node.js (v16 أو أعلى)
- MongoDB
- npm أو yarn

### التثبيت

1. **استنساخ المستودع**
```bash
git clone https://github.com/ezzaldeen-15/wheat-allergy-products-app.git
cd wheat-allergy-products-app
```

2. **تثبيت المتطلبات**
```bash
npm install
cd client && npm install && cd ..
```

3. **إنشاء ملف البيئة**
```bash
cp .env.example .env
```

4. **تكوين .env**
```
PORT=5000
NODE_ENV=development
MONGODB_URI=mongodb://localhost:27017/wheat-allergy-app
JWT_SECRET=your_secret_key_here
STRIPE_SECRET_KEY=your_stripe_key
STRIPE_PUBLIC_KEY=your_stripe_public_key
```

5. **تشغيل خادم MongoDB**
```bash
# على macOS مع Homebrew
brew services start mongodb-community

# على Linux
sudo systemctl start mongod
```

6. **تشغيل خادم التطوير**
```bash
npm run dev
```

هذا سيبدأ:
- الواجهة الخلفية: http://localhost:5000
- الواجهة الأمامية: http://localhost:3000

## 📚 نقاط نهاية API

### المصادقة
- `POST /api/auth/register` - تسجيل مستخدم جديد
- `POST /api/auth/login` - تسجيل دخول المستخدم

### المنتجات
- `GET /api/products` - الحصول على جميع المنتجات (يدعم التصفية والبحث)
- `GET /api/products/:id` - الحصول على منتج واحد
- `POST /api/products` - إنشاء منتج (فقط المسؤولين)
- `PUT /api/products/:id` - تحديث المنتج (فقط المسؤولين)

### الطلبات
- `GET /api/orders/user/:userId` - الحصول على طلبات المستخدم
- `GET /api/orders/:id` - الحصول على طلب واحد
- `POST /api/orders` - إنشاء طلب
- `PUT /api/orders/:id` - تحديث حالة الطلب
